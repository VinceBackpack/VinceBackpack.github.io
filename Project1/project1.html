UAE HOMES

About the Project

UAE HOMES is a responsive real estate web application designed to allow users to browse and discover available properties. Users can search through listings, view property information, and navigate between different pages to explore homes.

The application was built using React and React Router. I focused on creating a responsive and intuitive interface while organizing the application into reusable components. React Router was used to allow users to move between property listings and individual property details without having to reload the entire application.
